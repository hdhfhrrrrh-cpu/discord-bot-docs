SLASH

/티켓

관리자 전용

드롭다운 선택 메뉴가 포함된 고객 지원 티켓 발급 패널을 설정된 채널에 생성합니다.

드롭다운 선택 옵션 3종:
💻 개발자지원: 전용 채널 생성 후 안내 및 사진/이미지 첨부 대기
🚨 유저신고: 신고 대상 및 상세 사유 작성 모달 팝업
❓ 일반문의: 문의 내용 작성 모달 팝업 후 개인 문의 채널 생성
SLASH

/티켓설정

관리자 전용

티켓 패널에 표시될 커스텀 제목과 안내 설명글을 설정합니다.

명령어 인자:
title: 티켓 패널 제목
description: 상세 안내 설명문구
SLASH

/인증패널

관리자 전용

유저가 버튼을 눌러 로블록스 닉네임 인증을 진행할 수 있는 안내 패널을 출력합니다.

로블록스 API 검증 프로세스:

1. 모달 창에 입력된 닉네임 검증

2. 실존하는 유저일 경우 닉네임 변경 및 설정된 역할 자동 지급

SLASH

/인증설정

관리자 전용

인증 완료 시 부여될 닉네임 접두사(예: [사원], [훈련병]) 및 지급할 역할을 설정합니다. (중복 역할 가능)

명령어 인자:
prefix: 접두사 (예: [사원])
role1 / role2 / role3: 지급할 역할들
SLASH

/디엠보내기

관리자 전용

지정한 유저에게 작성용 모달 팝업을 띄워 1:1 디렉트 메시지를 발송합니다.

명령어 인자:
user: 메시지를 받을 대상 유저
SLASH

/모두에게디엠보내기

관리자 전용

서버 내 모든 일반 멤버에게 모달을 통해 입력한 메시지를 대량 발송합니다.

⚡ Rate Limit 자동 방지 처리 (0.5초 딜레이) 및 성공/실패 통계 보고서가 제공됩니다.
PREFIX (.)

.ban 유저 [사유]

멤버 차단 권한

서버 규칙을 위반한 유저를 서버에서 영구 차단합니다.

.ban @홍길동 광고 행위 위반
PREFIX (.)

.time 시간 유저 [사유]

멤버 관리 권한

지정한 시간 동안 유저에게 타임아웃(채팅 및 음성 차단) 조치를 적용합니다.

시간 단위: s(초), m(분), h(시간), d(일)
.time 10m @홍길동 도배

검색 결과가 없습니다

다른 키워드나 카테고리 필터로 다시 검색해 보세요.

자주 묻는 질문 (FAQ)

명령어 실행 및 기능 사용 시 주요 참고 사항

슬래시 커맨드가 작동하지 않거나 보이지 않습니다.

봇 실행 시 콘솔에 슬래시 명령어 동기화 완료 메시지가 출력되었는지 확인하세요. 디스코드 클라이언트 앱을 Ctrl + R 로 새로고침하거나, 서버 내 채널에 '애플리케이션 명령어 사용' 권한이 켜져 있는지 체크해야 합니다.

로블록스 인증 시 닉네임 변경 권한 에러가 납니다.

디스코드의 역할 계층 구조상 봇의 최고 역할 위치가 변경하려는 대상 멤버보다 위에 위치해야 합니다. 서버 설정 ➔ [역할] 메뉴에서 봇 역할 레이어를 더 높게 드래그해 옮겨주세요.
